# 🛒 ASP.NET MVC Product Management

## 📌 Giới thiệu

Hệ thống quản lý sản phẩm xây dựng bằng ASP.NET Core MVC.

---

## 🚀 Chức năng

* CRUD sản phẩm
* Lọc theo danh mục (Category)
* Tìm kiếm sản phẩm
* Upload hình ảnh
* Giỏ hàng cơ bản

---

## 🛠 Công nghệ

* ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* Bootstrap

---

## ⚙️ Cách chạy project

1. Clone repo:

```
git clone https://github.com/DDNguyen12/aspnet-mvc-product-management.git
```

2. Mở bằng Visual Studio

3. Chạy:

```
Update-Database
```

4. Run project
